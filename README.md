# 007SaaS Site

A lightweight static website and personal project hub for experiments in AI, automation, and growth.

## Project

The site is a home for selected projects, practical experiments, and professional experience in overseas growth, app publishing, analytics, and AI workflows. Experiments are labeled according to their stage; ideas under validation are not presented as finished products or proven outcomes.

## Tech and deployment

- Static frontend: HTML, CSS, and JavaScript.
- Hosting target: GitHub Pages.
- DNS: Cloudflare.
- The Telegram shortlink service on `link.007saas.com` is a separate service and is not part of this repository.
- Contact: `hello@007saas.com` (incoming email is currently routed through Cloudflare Email Routing).

## Repository structure

- `index.html` — homepage.
- `404.html` — not-found page.
- `SECURITY.md` — guidance for handling this public repository.

Internal migration inventories and work notes are intentionally kept out of the current public file tree.

## Development notes

This is an evolving project. Features and case studies will be described as they are tested and verified. The website should not be assumed to reproduce every feature of the previous WordPress site.

## Security

This repository is public. Never commit API keys, passwords, private keys, database exports, full site backups, customer information, or confidential working notes. See [SECURITY.md](SECURITY.md) for details.
